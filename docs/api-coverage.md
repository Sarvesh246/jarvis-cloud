A directory row does not mean an implemented or active API. `implemented` means a bounded read adapter exists; it does not promise every provider operation or live deployment configuration. `pending_contract` and `requires_user_connection` are unfinished integrations, not adapters. HTTP smoke success does not establish a production license or freshness of every returned record.
