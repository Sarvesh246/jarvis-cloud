Vaelo 0.1.5 for Windows, macOS, and Linux.

This update brings the desktop app up to date with the latest Vaelo interface and chat improvements:

- Redesigned desktop navigation, Desk, side panel, saved work, and full-page Settings.
- Updated app icons and a welcome screen that opens at the top.
- A working Stop button during streaming, prompt completion when a provider leaves its connection open, and recovery for stalled replies.
- Weather cards with condition emojis, highs and lows, forecast details, and source links. Shared location coordinates work even when a city lookup is slow.
- Cleaner answers without leaked tool-result delimiters, plus improved Markdown links, code fences, math, and workspace document rendering.
- More reliable image generation and downloads, active-reply synchronization, and session revocation.

Existing GitHub installations can get this signed update from Settings. Choose the installer for your operating system and processor for a new installation.

AI replies, research, account synchronization, and dictation require an internet connection. Cached conversations remain readable offline.

Updater signatures verify update authenticity. Installers without platform publisher certificates may still show Windows or macOS trust warnings. Microsoft Store packages are included for submission; Store updates depend on Microsoft's acceptance and distribution.
