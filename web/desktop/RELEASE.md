Vaelo 0.1.1 for Windows, macOS, and Linux.

This release brings the desktop interface up to date with the website:

- Interactive overviews, widgets, steps, graphs, file trees, galleries, image/code comparisons, receipts, QR links, 3D previews, and integration cards.
- Reliable rendering of valid visual data in ordinary JSON and unlabeled responses, with original-data access and readable fallbacks.
- Drag pinned conversations by their titles, with movement previews and keyboard reorder controls.
- Clearer reading typography, refined motion, and simpler Workroom files, notes, checks, and results.
- Global commands, local table exploration, review notes, and the interface guide.
- Remote HTTPS image and model previews now load in the desktop security policy.
- Settings shows the installed desktop version and provides signed updates for GitHub installations.

Existing desktop integrations remain available:

- Sign in with Google through your system browser.
- Chat, research, synchronized conversations, Workroom, attachments, approvals, and reply recovery share Vaelo's cloud service.
- Save exports with a native file dialog; copy text and receive notifications through the operating system.
- Record up to one minute of dictation and review the transcript before sending.
- Check for signed updates in Settings.

Choose the installer for your operating system and processor. AI, research, account synchronization, and dictation require an internet connection. Cached conversations remain readable offline.

Preview installers without platform certificates may show Windows or macOS trust warnings. Linux needs a desktop keyring implementing Secret Service for saved sign-in, and microphone access for dictation.
